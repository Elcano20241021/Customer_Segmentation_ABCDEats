# Customer_Segmentation_ABCDEats
 Customer segmentation project for ABCDEats using Value & Preference perspectives. Data Mining course – NOVA IMS 2024/25

## Overview
This project uses real-world customer transaction data to create business-relevant customer segments. We apply a multistep clustering process using:
- Value-based segmentation (based on total spending, frequency, order value)
- Preference-based segmentation (cuisine preferences & time-of-day behavior)

## Techniques Used
- Exploratory Data Analysis (EDA)
- Feature engineering & transformation
- Hierarchical clustering, K-Means, Gaussian Mixture Models, Emergent SOM
- Multivariate outlier detection (DBSCAN)
- Final profiling using classification (Decision Tree)
- Dimensionality reduction (t-SNE, UMAP)

## Models Evaluation
- Clustering evaluation: Silhouette Score, R² Score
- Semi-supervised classification for profiling outliers
- Feature importance for segmentation

## Business Applications
Tailored recommendations and marketing strategies were developed for:
- High-Value / Low-Value customers
- Cuisine preferences (Asian, American, Other)
- AM/PM order time behavior
- Regional customer behaviors
